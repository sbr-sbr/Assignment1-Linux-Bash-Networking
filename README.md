# Assignment1-Linux-Bash-Networking
A Linux diagnostic toolkit using Bash.The scripts collect system information, check disk usage and perform basic network checks.

## Structure
```
assignment-1/ 
├── README.md 
├── system-info.sh 
├── disk-check.sh 
├── network-check.sh 
├── grade.sh 
└── logs/ 
└── .gitkeep
```

## Files 
- **README.md** — Project documentation
- **system-info.sh** — System information script
- **disk-check.sh** — Disk usage check script
- **network-check.sh** — Network connectivity check script
- **grade.sh** — Grading/evaluation script
- **logs/** — Directory for log files
